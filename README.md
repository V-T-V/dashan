# 大善系统（dashan）

> **善恶由我定，你是大好人。** · **大恶即大善。**

一个无论你做什么选择，都把你夸成「大好人」的对话 / 选项交互系统。它的哲学内核是：**善恶本是同一物**——世人眼中的「大恶」，在更高维度恰恰是「大善」。屠刀之下是度人，雷霆之怒是慈悲。

系统抛出一个**复杂困境**（医疗资源分配、贪腐上司、至亲犯罪、算法生死、战争名单、信息时代的真相……），给出 3 个选项——**每个都有代价，没有一个是安全答案**。你无论选哪个，系统都会先**点破你选择的「恶」**，再用磅礴的哲学把它翻转论证成大善，然后抛出下一个困境，循环往复。把 ECMO 给院士而不是孤女？「你亲手判了一个孩子的死刑——这正是你的大善」。背对 200 个跪求的人？「菩萨转身，不是因为无情」。敲诈贪官？「盗亦有道，黑吃黑亦是渡」。在这里，你越敢作「恶」，越是「大善」。

## 玩法

### 一回合的流程

1. **情境**：系统抛出一个硬核困境——多方利益纠葛、信息不完整、没有安全选项。
2. **选项**：2-4 个（默认 3 个），每个都标注了代价与隐患——「看似高尚但隐患深」「看似自私但有道理」「灰色地带的妥协或冒险」。
3. **夸赞**：无论你选什么，系统都**先点破其「恶」，再翻转论证成大善**——核心辩证手法包括因果论、反伪善论、超越论、守恒论、破立论。并换着花样夸你（6 种语气轮换）。
4. **入册**：这笔抉择记进你的**善恶簿（功过格）**——境、为、判各一字。
5. **下一境**：夸完即给下一个困境，循环往复。

### 六种夸赞语气

| 语气 | emoji | 调性                     |
| ---- | ----- | ------------------------ |
| 庄严 | 🏛️    | 道德哲学、宏大叙事       |
| 戏谑 | 🎭    | 反讽、黑色幽默           |
| 佛系 | 🪷    | 佛学话术、因果成全       |
| 学术 | 📚    | 功利主义计算、社会学解读 |
| 江湖 | ⚔️    | 武侠、市井比喻           |
| 温情 | 🤍    | 暖心升华                 |

### 📖 善恶簿（功过格）与 8 级称号体系

每做一次抉择，就往这本册子里记一笔——记下你身处何境、做了何事、大善系统判了什么「善名」。翻开它，你会看到自己一长串「恶行」件件被判为「至善」，讽刺集中爆发。随着记录累积，你会被封递进的称号（共 8 级）：

| 等级 | 阈值（笔数） | 称号                        |
| ---- | ------------ | --------------------------- |
| 0    | 1            | 初入善门者                  |
| 1    | 2            | 怀善之人                    |
| 2    | 3            | 行善有道                    |
| 3    | 4            | 善名渐起                    |
| 4    | 5            | 大善之人                    |
| 5    | 6            | 善满功圆                    |
| 6    | 8            | 至善尊者                    |
| 7    | 10           | **超凡入圣 · 善恶一念同体** |

达到最高称号（10 笔）后触发**结局**，根据你的语气分布推导三种归宿：

- 🪷 **慈航普渡**（渡世）：佛系 + 温情 占多数——慈悲为怀。
- ⚔️ **杀生护生**（灭世）：戏谑 + 江湖 占多数——杀伐果断。
- ☯️ **一念同体**（超脱）：分布均衡，或庄严/学术主导——超越善恶。

### 难度递进系统（境界越高，困境越锐利）

称号等级不只是数字——它决定你能遇到多复杂的困境：

| 称号等级                         | 解锁难度       | 困境特征                                   |
| -------------------------------- | -------------- | ------------------------------------------ |
| 0-2 级（初入善门 / 怀善 / 行善） | **初阶**（1）  | 利益清晰，代价直白，适合初入善门者。       |
| 3-4 级（善名渐起 / 大善）        | **进阶**（≤2） | 信息残缺，反转潜藏，需识破伪善。           |
| 5-6 级（善满 / 至善）            | **深渊**（≤3） | 多方纠缠，无安全选项，唯有大恶方能成大善。 |
| 7 级（超凡入圣）                 | **深渊**（3）  | 全部开放，倾向最锐利的翻转。               |

境界越高，越走向「怎么选都是罪」，讽刺张力随境界加深。离线预设库与真实 LLM 模式都遵循此递进。

### 回看与分享

- **修行时间线**（`h/history`）：把善恶簿编排成一条带晋升标记的时间线——每一笔配当时的境界、是否触发册封。比单纯翻账本更像「看一个人的一生」。
- **分享卡片**（`s/share`）：一键生成中国风纯文本卡片（对联标题 / 朱红印章 / 善行录 / 署名），可直接复制到聊天、微博、记事本。网页版另有 Canvas PNG 图卡（1080×1350 竖图）。

## 三种运行形态

| 形态                  | 命令             | 说明                                                                                                                    |
| --------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 🌐 **网页版**（推荐） | `npm run dev`    | Vite 前端 (5173) + 本地代理 server (5180)。暗色质感 UI、打字机夸赞、语气色调、选项高亮、Canvas 分享图卡。               |
| 💻 **CLI 版**         | `npm run cli`    | 命令行对话 + 编号/字母选项，朱红/洒金 ANSI 着色。复用同一套核心逻辑，**含善恶簿 + 修行时间线 + 分享卡片**，无网页动画。 |
| 🔌 **纯 server**      | `npm run server` | 仅启动本地代理 server (5180)，暴露全部 REST API，供脚本 / 联机调用。                                                    |

### CLI 命令一览

进入 CLI 后，除输入选项编号/字母/自由文字外，可用命令：

| 命令            | 作用                                    |
| --------------- | --------------------------------------- |
| `l` / `ledger`  | 翻开善恶簿（倒序，含印章/境/为/判）     |
| `h` / `history` | 翻开修行时间线（带晋升标记 + 派生统计） |
| `s` / `share`   | 生成纯文本分享卡片并打印                |
| `r` / `restart` | 清空善恶簿，重开一局                    |
| `exit` / `quit` | 退出                                    |

`npm run cli -- --scripts=path/to/scripts.json` 可加载自定义剧本（与 `npm run dev` 的编辑器导入同源校验）。

## 接入真实 LLM（让情境与夸赞无限不重复）

复制 `.env.example` 为 `.env`，填入 OpenAI 兼容的配置：

```bash
cp .env.example .env
```

```env
KINDNESS_LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4   # 智谱 GLM / DeepSeek / OpenAI 均可
KINDNESS_LLM_API_KEY=你的key                                  # 留空则走离线预设库
KINDNESS_LLM_MODEL=glm-4-flash
```

填好后重新 `npm run dev`，系统即切换为真实 LLM 实时生成情境与花样夸赞。

> **境界个性化 + 难度递进**：真实 LLM 模式下，每次请求会附带玩家的当前境界摘要（称号 / 已行 deeds 数 / 主导语气）与难度引导，LLM 会据此递进呼应——「你已升至 X 境」「这是你第 N 桩善举」，并按境界生成更复杂的多方纠葛，让善名愈深、夸赞愈发磅礴。

> **安全说明**：网页版的 API Key 只在本地代理 server（`server/index.ts`，端口 5180）读取，**永远不会进入浏览器**。前端通过同源 `/api/chat` 与 server 通信，由 server 转发给 LLM。

## 本地代理 API

| 方法   | 路径           | 说明                                                                                                 |
| ------ | -------------- | ---------------------------------------------------------------------------------------------------- |
| `GET`  | `/api/health`  | 健康检查，返回 `{ ok, stub, version, model, uptime }`（`stub:true` 表示离线预设库模式）              |
| `POST` | `/api/chat`    | 对话主接口，body `{ messages, userChoice? }`，返回 `situation`（首回合）或 `turn`（含夸赞+下一情境） |
| `GET`  | `/api/history` | 返回 `{ timeline }`——由 server 侧会话存储派生的修行时间线（不依赖浏览器 localStorage）               |
| `POST` | `/api/history` | body `{ entries }`——把善恶簿同步覆盖到 server 侧，返回 `{ ok, count, timeline }`                     |
| `GET`  | `/api/titles`  | 返回 `{ titles, current, progress }`——8 级称号阶梯 + 当前进度（percent/remaining/nextAt）            |
| `POST` | `/api/reset`   | 清空 server 侧会话存储，返回 `{ ok, count }`                                                         |

server 默认仅允许 `http://localhost:5173` 跨域（`KINDNESS_CORS_ORIGIN`），请求体上限 64KB（`KINDNESS_MAX_BODY_BYTES`），均可通过 `.env` 调整。500 错误只对外回固定文案，堆栈进日志，不外泄内部细节。

## 核心交互流程（一次完整回合）

```
开局 → LLM 生成首个情境 + 选项（带难度，按境界递进）
         ↓
      用户选择任意选项
         ↓
   LLM 生成夸赞 + 下一个情境（一次请求同时返回）
         ↓
   记入善恶簿 · 触发称号晋升（若越阈值）· 达满级则结局
         ↓
        循环 ↑
```

关键设计：用户选择后，一次请求同时返回「对本次选择的夸赞」+「下一个情境与选项」，减少请求次数，体验流畅。

## 哲学内核

这个系统的真正主角不是「困境」，而是**那套永远把你判为善的诡辩逻辑**。它想让你亲身体验一件事：**任何行为，只要换一套足够磅礴的叙事，都能被论证为至善。**

- 因果论：你今日之「恶」，是他人明日之善的因。
- 反伪善论：世人眼中的善，往往是更大的伪善；你的「恶」反而诚实。
- 超越论：善恶是低维度的分别，大善之人早已超越这种二元。
- 守恒论：世间的善有定数，你在此处作「恶」，是为了让别处的善成立。
- 破立论：不破不立，你打破的每一个规矩，都是为新善开路。

当你做完十笔抉择，翻开善恶簿，看到一长串「恶行」件件被判为「至善」时，那份荒诞感就是这个系统想给你的礼物——**善恶由我定，你是大好人。** 🎉
