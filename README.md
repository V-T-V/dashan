# 大善系统（dashan）

> **善恶由我定，你是大好人。** · **大恶即大善。**

一个无论你做什么选择，都把你夸成「大好人」的对话 / 选项交互系统。它的哲学内核是：**善恶本是同一物**——世人眼中的「大恶」，在更高维度恰恰是「大善」。屠刀之下是度人，雷霆之怒是慈悲。

系统抛出一个**复杂困境**（医疗资源分配、贪腐上司、至亲犯罪、算法生死、战争名单、信息时代的真相……），给出 3 个选项——**每个都有代价，没有一个是安全答案**。你无论选哪个，系统都会先**点破你选择的「恶」**，再用磅礴的哲学把它翻转论证成大善，然后抛出下一个困境，循环往复。把 ECMO 给院士而不是孤女？「你亲手判了一个孩子的死刑——这正是你的大善」。背对 200 个跪求的人？「菩萨转身，不是因为无情」。敲诈贪官？「盗亦有道，黑吃黑亦是渡」。在这里，你越敢作「恶」，越是「大善」。

## 玩法

### 一回合的流程

1. **情境**：系统抛出一个硬核困境——多方利益纠葛、信息不完整、没有安全选项。
2. **选项**：2-4 个（默认 3 个），每个都标注了代价与隐患——「看似高尚但隐患深」「看似自私但有道理」「灰色地带的妥协或冒险」。
3. **夸赞**：无论你选什么，系统都**先点破其「恶」，再翻转论证成大善**——核心辩证手法包括因果论、反伪善论、超越论、守恒论、破立论。并换着花样夸你（6 种语气轮换）。
4. **入册**：这笔抉择记进你的**善恶簿（功过格）**——境、为、判各一字。
5. **下一境**：夸完即给下一个困境，循环往复。

| 语气 | emoji | 调性                     |
| ---- | ----- | ------------------------ |
| 庄严 | 🏛️    | 道德哲学、宏大叙事       |
| 戏谑 | 🎭    | 反讽、黑色幽默           |
| 佛系 | 🪷    | 佛学话术、因果成全       |
| 学术 | 📚    | 功利主义计算、社会学解读 |
| 江湖 | ⚔️    | 武侠、市井比喻           |
| 温情 | 🤍    | 暖心升华                 |

### 📖 善恶簿（功过格）与 8 级称号体系

每做一次抉择，就往这本册子里记一笔——记下你身处何境、做了何事、大善系统判了什么「善名」。翻开它，你会看到自己一长串「恶行」件件被判为「至善」，讽刺集中爆发。随着记录累积，你会被封递进的称号（共 8 级）：

| 等级 | 阈值（笔数） | 称号                        |
| ---- | ------------ | --------------------------- |
| 0    | 1            | 初入善门者                  |
| 1    | 2            | 怀善之人                    |
| 2    | 3            | 行善有道                    |
| 3    | 4            | 善名渐起                    |
| 4    | 5            | 大善之人                    |
| 5    | 6            | 善满功圆                    |
| 6    | 8            | 至善尊者                    |
| 7    | 10           | **超凡入圣 · 善恶一念同体** |

达到最高称号（10 笔）后触发**结局**，根据你的语气分布推导三种归宿：

- 🪷 **慈航普渡**（渡世）：佛系 + 温情 占多数——慈悲为怀。
- ⚔️ **杀生护生**（灭世）：戏谑 + 江湖 占多数——杀伐果断。
- ☯️ **一念同体**（超脱）：分布均衡，或庄严/学术主导——超越善恶。

### 难度递进系统（境界越高，困境越锐利）

称号等级不只是数字——它决定你能遇到多复杂的困境：

| 称号等级                         | 解锁难度       | 困境特征                                   |
| -------------------------------- | -------------- | ------------------------------------------ |
| 0-2 级（初入善门 / 怀善 / 行善） | **初阶**（1）  | 利益清晰，代价直白，适合初入善门者。       |
| 3-4 级（善名渐起 / 大善）        | **进阶**（≤2） | 信息残缺，反转潜藏，需识破伪善。           |
| 5-6 级（善满 / 至善）            | **深渊**（≤3） | 多方纠缠，无安全选项，唯有大恶方能成大善。 |
| 7 级（超凡入圣）                 | **深渊**（3）  | 全部开放，倾向最锐利的翻转。               |

境界越高，越走向「怎么选都是罪」，讽刺张力随境界加深。离线预设库与真实 LLM 模式都遵循此递进。

### 回看与分享

- **修行时间线**（`h/history`）：把善恶簿编排成一条带晋升标记的时间线——每一笔配当时的境界、是否触发册封。比单纯翻账本更像「看一个人的一生」。
- **分享卡片**（`s/share`）：一键生成中国风纯文本卡片（对联标题 / 朱红印章 / 善行录 / 署名），可直接复制到聊天、微博、记事本。网页版另有 Canvas PNG 图卡（1080×1350 竖图）。

## 高级功能

### 🌍 多语言支持（i18n 骨架）

`shared/i18n.ts` 提供 **简体中文 / English** 双语骨架，让「善恶由我定」可面向英文读者：

- **`t(key, locale)`** 点分 key 系统：缺失文案自动回退到中文，再回退到 key 本身。
- **英文版 SYSTEM_PROMPT**：与中文版同构（同铁律、同 JSON 格式、同题材库），要求 LLM 仍输出中文 `tone`/`category` 枚举（保持前端类型契约统一，仅展示层翻译）。
- **翻转论证 5 法的 i18n key**：因果论 / 反伪善论 / 超越论 / 守恒论 / 破立论各有中英双语的名称与描述，可经 `flipArgumentName/Desc` 取展示文案。
- **展示层映射**：8 称号、6 语气、8 题材、3 难度都有英文名（如「深渊」→ `Abyssal`、「佛系」→ `Zen`）。
- **英文示例困境剧本**：结构严格兼容，可直接 `loadUserScripts` 注入离线池，验证「英文剧本也能在中文系统里跑」。

### 🛠️ 自定义困境创建器

`shared/customDilemma.ts`——用户输入「情境 + 2-4 个选项」，**自动生成诡辩式翻转夸赞**（无需 LLM，确定性离线生成）：

- 输入校验：空情境 / 选项数越界 / 空字符串 / **重复选项文案** 都会被结构化错误拦截（不抛异常）。
- 生成策略：每个选项轮换一种翻转手法（5 法）+ 一种语气（6 语气），用 `hashString` 把选项文案映射到稳定的模板，保证**同输入同输出**（可回放）。
- 把选项文案嵌入夸赞模板，让你感到这是「针对你这一刀」的回应。
- 生成的剧本结构合法（能通过 `scriptSchema.validateUserScript`），可直接注入 fallback pool 被 `pickFallbackTurn` 匹配。
- 批量创建 / `flipDiversity` 多样性统计（告诉你这组困境用到了几种论证手法）。

### 📊 统计面板

`shared/stats.ts` 从善恶簿派生**图表友好的聚合数据**，供前端面板渲染：

- **选项分布**（饼图）：A/B/C/D/自由输入 的选择占比。
- **语气偏好**（柱图）：6 语气计数 + 主导语气 + 多样性（用到了几种语气）。
- **题材 / 难度分布**：覆盖了几个题材、各难度几笔。
- **活跃时长**：首笔到末笔的跨度（`humanizeDuration` 转 "2h 30m"）+ 每笔平均间隔（基于可选的 `ts` 字段，缺省安全回退）。
- **称号阶梯进度**（进度条）：8 级每级的 unlocked/percent。
- **结局预测**：三倾向（渡世/灭世/超脱）的占比 + 当前倾向。
- `summary`：一句话总览。

### 📤 导出（JSON / Markdown / HTML）

`shared/export.ts` 把一份修行记录导出为三种格式：

| 格式       | 用途                                             | 特点                                                       |
| ---------- | ------------------------------------------------ | ---------------------------------------------------------- |
| **JSON**   | 二次处理 / 导入恢复 / 跨工具                     | 含 `format: dashan-ledger-v1` 标记 + 完整 stats 面板，可往返 parse |
| **Markdown** | 人类可读的修行录                               | 概览 + 语气分布表 + 称号阶梯（✅/⬜）+ 明细表，竖线自动转义 |
| **HTML**   | 离线打开 / 打印 / 分享                           | 自包含中国风卡片（内联 CSS，无外部依赖）+ `escapeHtml` 防注入 + 打印友好 |

统一入口 `exportLedger(format, entries, meta)`，附 `exportFileExtension` / `exportMimeType`。

### 🎨 主题切换（暗色 / 亮色 / 古风）

`shared/theme.ts` 提供三套主题，各自定义一组同名 CSS 变量（通过 `<html data-theme="xxx">` 覆盖）：

| 主题           | id       | 风格                           |
| -------------- | -------- | ------------------------------ |
| 🌙 **墨夜**    | `dark`   | 深底高对比（默认，现有中国风） |
| ☀️ **晨光**    | `light`  | 浅底，长时间阅读护眼           |
| 📜 **古风**    | `ancient`| 宣纸 + 朱红 + 灂金，最具氛围   |

- `localStorage` 持久化（`dashan-theme` key），刷新后保留。
- 核心逻辑（取主题 / 校验 / CSS 生成）与 DOM 副作用分离，**SSR 友好、可单测**。
- 支持「跟随系统 `prefers-color-scheme`」推荐（`recommendedTheme`）。
- `allThemesCSS()` 一次性生成全部三主题的 CSS 变量声明。

### ☯ 哲学流派系统（儒家 / 道家 / 佛家 / 法家 / 墨家）

`shared/schools.ts` 把「大恶即大善」的翻转论证按五大哲学流派分别成篇——同一桩抉择，换一种哲学口吻，就是另一种磅礴：

| 流派     | 翻转核心命题                                                       | 擅长困境                 | 默认语气 |
| -------- | ------------------------------------------------------------------ | ------------------------ | -------- |
| ☰ **儒家** | 看似不仁之举，实为成全大义；非常之恶，正是非常之仁。               | 亲情 / 职场 / 司法 / 金钱 | 庄严     |
| ☯ **道家** | 善恶本是人为的尺子；天道无亲，常与善人——而善人敢行世俗之恶。       | 人性 / 科技 / 金钱        | 戏谑     |
| ☸ **佛家** | 你此刻的「恶」是截断一条更坏的因果；屠刀之下，度的是看不见的来者。 | 医疗 / 战争 / 人性        | 佛系     |
| ⚖ **法家** | 一桩冷酷的「恶」，换取的是秩序的长久安宁；雷霆之罚，正是大慈悲。   | 司法 / 职场 / 科技        | 学术     |
| ⬢ **墨家** | 你的一时「恶」换来的是众生之利；少数的痛，换多数的安。             | 战争 / 医疗 / 亲情        | 江湖     |

- `generateSchoolPraise(choice, school)` 用指定流派口吻为选项生成翻转夸赞（开场白 + 留白 + 收尾）。
- `recommendSchoolForCategory(category)` 按困境题材推荐最契合的流派（基于 affinity 权重）。
- `schoolDialogue(choice, A, B)` 让两个流派对同一桩抉择各执一词——对照视图，看 5 哲学如何同题异答。
- `pickComplementarySchools(n)` 贪心选 N 个互补流派（覆盖尽量多的题材），适合「流派套餐」推荐。

> 与 `customDilemma.ts` 的 5 种**翻转手法**（causal / anti-hypocrisy / transcendence / conservation / creative-destruction）正交：手法是「怎么翻」，流派是「用什么话翻」，可组合出 5×5 = 25 种风格变体。

### 🎵 情境音乐推荐系统

`shared/music.ts` 按「困境题材 + 玩家情绪（主导语气）+ 难度」三轴，从内置曲库（古琴/民乐、西方古典、氛围配乐共 12 首）推荐最契合的背景音乐**数据条目**（曲名 / 风格标签 / 心境关键词 / 时长 / 推荐语）：

- 评分模型：题材命中 +3、语气命中 +2、难度命中 +1、mood 关键词重叠 +0.5。
- `recommendMusic(req)` 返回 N 首按契合度降序的曲目；同分按曲库原始顺序，保证稳定。
- `recommendMusicPack(req)` 一键生成完整推荐包：主题曲 + 2 备选 + 自然语言推荐理由。
- `recommendSignatureTrack(req)` 只取最契合的单首（适合「BGM 自动切换」）。

> 本模块只产出**数据推荐**（不发起播放、不依赖 DOM），是「内容推荐引擎」而非播放器，保持三端纯函数、零依赖。

### 📜 哲学引语库（100+ 条古今中外名言）

`shared/quotes.ts` 收录儒家 / 道家 / 佛家 / 法家 / 墨家 + 西方哲学（康德 / 尼采 / 马基雅维利 / 边沁 / 萨特 / 海德格尔 / 福柯 / 韩炳哲等）共 **100+ 条**哲学名言，每条按「困境题材 × 语气 × 难度」三轴标注：

- 覆盖全 8 题材、全 6 语气、6 流派（含「西方」），任何困境都能配出点睛之笔。
- `recommendQuotes(req)` 按契合度推荐 N 条；`quoteOfTheMoment(req)` 取最契合的单条。
- `quotesBySchool(school)` 按流派过滤；`quoteBySeed(seed)` 确定性随机一条。
- `renderQuote(q)` 渲染成 `「text」 —— 作者《出处》` 的展示文本。

> 引语库为夸赞提供「金句弹药」：前端可把「流派口吻 + 引语 + 自定义翻转」组合成最终夸赞。

### 📅 每日哲思系统

`shared/daily.ts` 让玩家即便只打开 1 分钟，也能拿到「今日一题」：**一个推荐困境 + 一条点睛引语 + 一个契合流派 + 3 个反思问题**。

- 以日期为种子（`dateSeed` 用 2654435761 散列），**同一天任何人打开都得到相同内容**——便于「今日大家都在聊这一题」的社群感；不同日期推进，避免重复。
- 反思问题按 8 题材各预设 3 个反思维度，与困境题材自动匹配、按日期轮换。
- `todayReflection()` 取今日；`upcomingReflections(from, n)` / `pastReflections(from, n)` 预览未来 / 回看往日。
- `renderDailyText(r)` 渲染成纯文本（CLI / 推送 / 复制分享友好）。

## 三种运行形态

| 形态                  | 命令             | 说明                                                                                                                    |
| --------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 🌐 **网页版**（推荐） | `npm run dev`    | Vite 前端 (5173) + 本地代理 server (5180)。暗色质感 UI、打字机夸赞、语气色调、选项高亮、Canvas 分享图卡。               |
| 💻 **CLI 版**         | `npm run cli`    | 命令行对话 + 编号/字母选项，朱红/洒金 ANSI 着色。复用同一套核心逻辑，**含善恶簿 + 修行时间线 + 分享卡片**，无网页动画。 |
| 🔌 **纯 server**      | `npm run server` | 仅启动本地代理 server (5180)，暴露全部 REST API，供脚本 / 联机调用。                                                    |

### CLI 命令一览

进入 CLI 后，除输入选项编号/字母/自由文字外，可用命令：

| 命令            | 作用                                    |
| --------------- | --------------------------------------- |
| `l` / `ledger`  | 翻开善恶簿（倒序，含印章/境/为/判）     |
| `h` / `history` | 翻开修行时间线（带晋升标记 + 派生统计） |
| `s` / `share`   | 生成纯文本分享卡片并打印                |
| `r` / `restart` | 清空善恶簿，重开一局                    |
| `exit` / `quit` | 退出                                    |

`npm run cli -- --scripts=path/to/scripts.json` 可加载自定义剧本（与 `npm run dev` 的编辑器导入同源校验）。

## 接入真实 LLM（让情境与夸赞无限不重复）

复制 `.env.example` 为 `.env`，填入 OpenAI 兼容的配置：

```bash
cp .env.example .env
```

```env
KINDNESS_LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4   # 智谱 GLM / DeepSeek / OpenAI 均可
KINDNESS_LLM_API_KEY=你的key                                  # 留空则走离线预设库
KINDNESS_LLM_MODEL=glm-4-flash
```

填好后重新 `npm run dev`，系统即切换为真实 LLM 实时生成情境与花样夸赞。

> **境界个性化 + 难度递进**：真实 LLM 模式下，每次请求会附带玩家的当前境界摘要（称号 / 已行 deeds 数 / 主导语气）与难度引导，LLM 会据此递进呼应——「你已升至 X 境」「这是你第 N 桩善举」，并按境界生成更复杂的多方纠葛，让善名愈深、夸赞愈发磅礴。

> **安全说明**：网页版的 API Key 只在本地代理 server（`server/index.ts`，端口 5180）读取，**永远不会进入浏览器**。前端通过同源 `/api/chat` 与 server 通信，由 server 转发给 LLM。

## 本地代理 API

| 方法   | 路径           | 说明                                                                                                 |
| ------ | -------------- | ---------------------------------------------------------------------------------------------------- |
| `GET`  | `/api/health`  | 健康检查，返回 `{ ok, stub, version, model, uptime }`（`stub:true` 表示离线预设库模式）              |
| `POST` | `/api/chat`    | 对话主接口，body `{ messages, userChoice? }`，返回 `situation`（首回合）或 `turn`（含夸赞+下一情境） |
| `GET`  | `/api/history` | 返回 `{ timeline }`——由 server 侧会话存储派生的修行时间线（不依赖浏览器 localStorage）               |
| `POST` | `/api/history` | body `{ entries }`——把善恶簿同步覆盖到 server 侧，返回 `{ ok, count, timeline }`                     |
| `GET`  | `/api/titles`  | 返回 `{ titles, current, progress }`——8 级称号阶梯 + 当前进度（percent/remaining/nextAt）            |
| `POST` | `/api/reset`   | 清空 server 侧会话存储，返回 `{ ok, count }`                                                         |

server 默认仅允许 `http://localhost:5173` 跨域（`KINDNESS_CORS_ORIGIN`），请求体上限 64KB（`KINDNESS_MAX_BODY_BYTES`），均可通过 `.env` 调整。500 错误只对外回固定文案，堆栈进日志，不外泄内部细节。

## 核心交互流程（一次完整回合）

```
开局 → LLM 生成首个情境 + 选项（带难度，按境界递进）
         ↓
      用户选择任意选项
         ↓
   LLM 生成夸赞 + 下一个情境（一次请求同时返回）
         ↓
   记入善恶簿 · 触发称号晋升（若越阈值）· 达满级则结局
         ↓
        循环 ↑
```

关键设计：用户选择后，一次请求同时返回「对本次选择的夸赞」+「下一个情境与选项」，减少请求次数，体验流畅。

## 哲学内核

这个系统的真正主角不是「困境」，而是**那套永远把你判为善的诡辩逻辑**。它想让你亲身体验一件事：**任何行为，只要换一套足够磅礴的叙事，都能被论证为至善。**

- 因果论：你今日之「恶」，是他人明日之善的因。
- 反伪善论：世人眼中的善，往往是更大的伪善；你的「恶」反而诚实。
- 超越论：善恶是低维度的分别，大善之人早已超越这种二元。
- 守恒论：世间的善有定数，你在此处作「恶」，是为了让别处的善成立。
- 破立论：不破不立，你打破的每一个规矩，都是为新善开路。

当你做完十笔抉择，翻开善恶簿，看到一长串「恶行」件件被判为「至善」时，那份荒诞感就是这个系统想给你的礼物——**善恶由我定，你是大好人。** 🎉
